# Get Ripped Or Die Trying

Official website for GRODT, a fitness apparel brand based in Detroit, MI.

## Structure

- `index.html` - single page site: hero, launch special, shop, lookbook, story, email signup
- `css/styles.css` - all styles
- `js/script.js` - mobile menu, scroll reveal, cart counter, signup form
- `assets/` - logo and photography

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8080
```

Then visit http://localhost:8080
