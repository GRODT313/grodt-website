Return Policy

Last updated: August 4, 2026

We want you to be solid with your gear. If something is not right, here is how returns work at Get Ripped Or Die Trying.

Return Window

You may request a return within 30 days of the delivery date for unused items in original condition with tags attached (if applicable).

Eligible Items

  • Unworn, unwashed apparel free of stains, odors, and damage
  • Items in original packaging when possible
  • Incorrect sizes or defective items are eligible when reported promptly

Non-Returnable Items

  • Final sale, clearance, or marked non-returnable items
  • Items that have been worn, washed, altered, or damaged by the customer
  • Gift cards or digital items, if offered

How to Start a Return

  1. Email mal@getrippedodt.com with your order number, item(s), size(s), and reason for return
  2. Wait for return approval and shipping instructions
  3. Ship the item(s) as directed. Return shipping costs are the customer's responsibility unless the item arrived defective or we made an error

Exchanges

If you need a different size, contact us. Exchanges depend on available inventory. If your size is unavailable, we can process a return and refund so you can reorder when stock returns.

First 50 Launch Sets

Launch special sets follow the same delivery and defect rules. If a First 50 set arrives damaged or incorrect, contact us right away and we will make it right.

Contact

Return questions: mal@getrippedodt.com
